每表均满足“输入 = 参与保留/合并 + 去重 + 隔离”。用户和电影会把同一 ID 的多个非重复属性变体合并成一条净表行，所以“参与保留/合并的来源行”可能大于“净表行”。评分表中同一事件的异值冲突整组隔离，优先于去重，因此虽然预分析发现许多完整重复行，本次正式处置计入评分冲突隔离而不是去重。评分隔离的主要原因包括无效评分 43,885 行、无效时间戳 28,881 行、同事件评分冲突 40,103 行、字段数错误 13,503 行；完整原因分布在报告中。
