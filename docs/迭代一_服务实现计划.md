# 迭代一服务实现计划

历史计划：本文件记录最初的规则式任务服务实现。当前大模型重构方案见 `docs/大模型Agent_设计与实施计划.md`，运行与手测步骤见 `docs/迭代一_手动测试.md`。

目标：在既有 Hadoop 清洗与评分流水线之上，完成一次自然语言请求到真实结果展示的闭环。

1. 将 Hadoop 路径与配置改为环境变量可覆盖，同时保留既有默认值；驱动在输入校验或集群检查失败时写清楚失败状态。
2. 新增本地任务服务：仅接受已登记的 v1 清洗规则；任务异步运行且同一时间只运行一个 Hadoop 流水线；提供状态、报告、净表样例和报告下载接口。失败、超时、服务重启均有明确状态。
3. 新增基于报告的问答工具：解释评分变化、数据处置、未解决问题和时间切分；不支持的问题明确说明可查询范围，不生成数值。
4. 新增无外部依赖的静态页面，提供自然语言输入、任务状态、评分与行数对比、审计样例、数据样例、报告下载和追问。
5. 用现有 Hadoop 规则测试及新增服务接口测试验证成功、拒绝、失败和历史报告读取；编写手动测试文档，并区分本机未能实跑的环节。

服务仅绑定本机回环地址，默认端口 8765。Windows 上通过 WSL Ubuntu 调用原有 Python 驱动；Linux 上直接调用。现有正式报告可用于历史结果浏览，但不能冒充本次新任务结果。
